使用步骤
  1. 安装依赖：pip install -r requirements.txt 然后 playwright install chromium
  2. 启动服务：uvicorn app.main:app --host 127.0.0.1 --port 8000
  3. 打开内嵌浏览器页 → 选站点 → 连接 → 在画面里直接登录（扫码/密码/滑块），点检测登录确认。登录态会持久化，之后长期复用（无需命令行）。
  4. （可选）在同一页点开始录制接口，在画面里发一句“你好”，再停止录制，写入 fixtures 以精修解析/启用通义 HTTP 快路径。
  5. 到聊天界面选模型开聊；或用任意 OpenAI 客户端指向 http://127.0.0.1:8000/v1（api_key 随意，除非设了 W2A_API_KEY）。
  6. 命令行兜底（不用 UI 时）：python -m scripts.login <provider>、python -m scripts.recon <provider>。
